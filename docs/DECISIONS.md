# Реестр решений

Короткий журнал архитектурных и продуктовых решений по всему проекту. Подробности —
в спецификациях модулей (`MODULE_4A.md` — решения Р1–Р36 и §5), здесь — что решено, почему
и где это влияет.

**Правила ведения:**
- запись не редактируется задним числом: изменённое решение получает новую запись, а у старой
  статус меняется на «заменено D-NNN»;
- статусы: `принято`, `предложено` (ждёт решения владельца), `заменено`, `отменено`;
- новые записи добавляются в конец; номер не переиспользуется.

Формат записи:

```
## D-NNN. Название
Дата · Статус · Модуль
Решение. Почему. Следствия. Ссылки.
```

## Модуль 4а

### D-010. Роли admin и student; консоль — канал владельца
2026-10-26 · принято · 4а.1
Все админы в вебе равноправны. Создание и отключение админов, сброс 2FA, токены воркеров —
только через `judgectl`. Р1, Р2.

### D-011. Серверные сессии, argon2id, обязательная 2FA для админов
2026-10-26 · принято · 4а.1
Cookie `__Host-session`, CSRF-токен + проверка Origin, ограничение перебора прежде всего
по логину. Вход админа открыт из интернета, поэтому TOTP обязателен. `AUTH.md`.

### D-012. Вход по QR для учеников
2026-10-26 · принято · 4а.1
Одноразовый токен на 7 дней, токен передаётся во фрагменте URL. Для админов запрещён. Р10.

### D-013. Пользователей не удаляют, кроме созданных по ошибке
2026-10-28 · принято · 4а.2
Удаление разрешено только при отсутствии следов (задачи, контесты, посылки, аудит от его
имени); иначе — отключение. Откат импорта — по тем же правилам. Уточняет Р9.

### D-014. Время: хранение в `timestamptz`, API — UTC с `Z`
2026-10-28 · принято · 4а.2, 4а.3
`JUDGE_TIMEZONE` — только для вывода judgectl и времени без смещения в `contest.yaml`.
Отображение в поясе пользователя — во фронтенде (см. D-024).

### D-015. Идентичность версии — `content_sha256`
2026-10-28 · принято · 4а.2
Хеш по байтам всех файлов пакета, кроме мусорных. `manifest_sha256` — ключ кэша воркера. Р29.

### D-016. Защита импорта — лимит объёма, а не коэффициент сжатия
2026-10-28 · принято · 4а.2
Лимит распакованного объёма, ранний отказ по заголовкам, CRC. В архиве допустимы только
методы stored и deflate. Коэффициент сжатия по умолчанию выключен. `PROBLEM_IMPORT.md`.

### D-017. Отдача загруженных файлов — защита от XSS
2026-10-28 · принято · 4а.3
`nosniff`, CSP `sandbox`. Встраивание в страницу — только растровые картинки; SVG и HTML —
всегда как вложение. Путь к файлу ищется только среди файлов версии. MODULE_4A §5.7
(список картинок уточняется в D-026).

### D-018. Админский API — в том же публичном приложении, без операций с админами
2026-10-28 · принято · 4а.3
Префикс `/api/admin`, единый формат ошибок, курсорная пагинация, загрузки сырым телом без
multipart, OpenAPI — файлом в репозитории, не по сети. `ADMIN_API.md`.

## Дельта от 2 ноября 2026

### D-020. Группы (классы) как адресаты контестов
2026-11-02 · принято · 4а.3
Группы с составом «многие ко многим», подключаются к контестам. Доступ вычисляется по
текущему составу: новый ученик получает доступ сразу, убранный теряет будущий доступ, но
сохраняет историю. Группы архивируются, а не удаляются. Преподаватели видят всё. Заменяет
положение «групп нет» (CLAUDE.md, Р19/Р23).

### D-021. Режим доступа к контесту: код/QR, группы, оба
2026-11-02 · принято · 4а.3
`access_mode ∈ {open, code, groups, code_or_groups}`. Админ привязывает контест к группе,
и её ученики входят без кода. `open` сохранён (архив для всех, `practice`, `dev`). Участие
создаётся при первом входе, способ входа сохраняется в `joined_via`.

### D-022. Личный таймер при доступе через группы
2026-11-02 · принято · 4а.3
Участие создаётся при первом входе, личный таймер запускается только кнопкой «Начать» (Р21
без изменений).

### D-023. Сроки на задаче контеста
2026-11-02 · принято · 4а.3
`available_from`, `due_at`; после срока — политика просмотра условия и сдачи (нет / с пометкой
«с опозданием» / да); личные и групповые продления; `note_md`. Срок проверяется только на
сервере, в UTC, по времени получения запроса. Ученик всегда видит свои посылки и оценки.

### D-024. Часовой пояс в профиле
2026-11-02 · принято · 4а.3
Необязательное поле `users.timezone` (IANA). Показывает время фронтенд.

### D-027. Виды элементов контеста и ручные задания

2026-11-02 · принято · 4в.2

### D-030. Библиотека материалов
2026-11-02 · принято · 4в.4
Версии неизменяемы, теги, ссылки `[[памятка:slug]]` и `references` в `problem.yaml`

и скрытие условия доступ не отменяют. Архивация вместо удаления. Исключение из Р19 — только
для материалов.
