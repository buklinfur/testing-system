# Отдача загруженных файлов

Файлы, которые прислали люди, — файлы пакетов задач (условия, картинки, тесты), исходники посылок, а позже картинки
условия в API ученика (4б.1) и вложения (4в.3), — сервер отдаёт так, чтобы браузер **никогда** не исполнил их как
страницу (XSS) и не показал под чужим видом. Все такие ответы делает одна функция —
[`backend/app/content_files.py`](../backend/app/content_files.py), `file_response`. Решение — D-070 (уточняет D-017,
D-026 и правило «тип по расширению» из `MODULE_4A.md` §5.7). Тесты — `tests/test_content_files_units.py`,
`tests/pg/test_admin_problems_contests_pg.py`, `tests/pg/test_admin_submissions_pg.py`.

## 1. Какой это файл: имя и содержимое вместе

Сервер читает **первые 8 КБ** файла (`BlobStore.open`, файл целиком не читается) и решает чистой функцией
`decide(имя, первые байты)`:

| Содержимое (сигнатура) | Имя | Ответ |
|---|---|---|
| PNG `89 50 4E 47 0D 0A 1A 0A`, JPEG `FF D8 FF`, WebP `RIFF????WEBP` | `.png`, `.jpg`, `.jpeg`, `.webp` | **показывается** (`inline`), тип — **по содержимому**: `.jpg` с PNG внутри — `image/png` |
| картинка PNG/JPEG/WebP | любое другое (`.txt`, `.in`, без расширения) | `application/octet-stream`, вложением |
| не картинка (HTML, SVG, что угодно) | картиночное (`pic.png`) | `application/octet-stream`, вложением |
| GIF, SVG, HTML и всё прочее | любое | `application/octet-stream`, вложением (D-026: GIF тоже) |
| текст: нет байта NUL и это UTF-8 | текстовое (`.in`, `.out`, `.ans`, `.txt`, `.md`, `.py`, `.c`, `.cpp`, `.h`, `.yaml`, `.json`, …) или исходник посылки | `text/plain; charset=utf-8`, вложением |
| не UTF-8 (например, **cp1251**) или есть NUL | текстовое или исходник | `application/octet-stream`, вложением |
| zip `PK 03 04` | архив посылки | `application/zip`, вложением |
| не zip | архив посылки | `application/octet-stream`, вложением |

**Текст.** Проверяются первые 8 КБ: в них нет NUL, и они декодируются как UTF-8. Если файл длиннее, многобайтная буква,
разрезанная концом этих 8 КБ, допустима (продолжение — в следующих байтах); в конце самого файла — нет. Файл в cp1251
(старый Блокнот, Excel) отдаётся вложением как двоичный: показать его текстом значило бы показать кракозябры, а угадывать
кодировку сервер не берётся. Список текстовых расширений — `TEXT_SUFFIXES` в коде.

Картинки в браузере показываются только когда и байты, и имя говорят «картинка PNG/JPEG/WebP»; содержимое может только
сузить ответ, никогда — расширить. Путь файла ищется только среди файлов версии (`files`) или в строке посылки, к файловой
системе по пути из URL обращения нет.

## 2. Заголовки каждого ответа (200 и 304)

| Заголовок | Значение | Зачем |
|---|---|---|
| `X-Content-Type-Options` | `nosniff` | браузер не угадывает тип сам |
| `Content-Security-Policy` | `sandbox; default-src 'none'` | даже открытый файл не выполнит скрипт и ничего не загрузит |
| `Cache-Control` | `private, no-cache` | общие кэши не хранят; браузер каждый раз спрашивает сервер — доступ мог пропасть |
| `ETag` | `"<sha256 файла>"` | содержимое неизменно (адресация по хешу): повторный запрос — дешёвый 304 |
| `Content-Disposition` | `inline` / `attachment; filename="<ASCII>"; filename*=UTF-8''<имя>` | §3 |
| `Content-Type` | по таблице §1 | — |

**304.** `If-None-Match` по RFC 9110: `*` или список тегов, сравнение слабое (`W/"…"` совпадает с `"…"`). Совпал — 304
с теми же заголовками и пустым телом. Ответ 304 даёт только `file_response`, а её зовёт эндпоинт **после** проверки
доступа и поиска файла: без сессии или без права на файл ответ (401/403/404) от `If-None-Match` не зависит, тег файла
не раскрывается.

## 3. Имя файла (`Content-Disposition`, RFC 6266)

* только базовое имя: путь (`../`, `a/b/`, `a\b\`) отрезается;
* вырезаются управляющие и «форматные» символы Unicode (переводы строк, `\r`, NUL, знаки направления текста вроде
  U+202E), а также `"`, `\` и `;`;
* не длиннее 150 символов (расширение сохраняется); пустое имя или только точки — `file`;
* `filename="…"` — ASCII-запас: русские буквы транслитом (`Задача 1.png` → `Zadacha_1.png`), прочее — `_`; имя без
  букв — `file.<расширение>`;
* `filename*=UTF-8''…` — полное очищенное имя в процентной кодировке (кириллица, `%`, эмодзи).

## 4. Отдача

Тело идёт потоком кусками по 1 МБ (`BlobStore.iter_chunks`); для решения о типе читаются только первые 8 КБ (и один
байт, чтобы знать, есть ли продолжение). Файл, записанный в базе, но пропавший из хранилища, — 404 `file_missing`.

## 5. Кто вызывает

| Эндпоинт | Вызов |
|---|---|
| `GET /api/admin/problems/{slug}/versions/{n}/files/{путь}` | `file_response(blobs, sha, путь, request=request)` |
| `GET /api/admin/submissions/{id}/source` | исходник: `text=True`; архив: `media_type="application/zip"` (подтверждается сигнатурой) |
| 4б.1: картинки условия в API ученика | тот же `file_response` после проверки доступа ученика к задаче |
| 4в.3: вложения | тот же `file_response`; квоты и белый список типов — при загрузке |

Сигнатура `file_response` совместима с прежней: новый необязательный параметр `request` (для `If-None-Match`).
