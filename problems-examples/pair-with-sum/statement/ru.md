# Любая пара с заданной суммой

Дано целое число $n$. Выведите любые два целых числа $a$ и $b$ такие, что $a + b = n$.

## Формат входных данных

Одно целое число $n$, $|n| \le 10^9$.

## Формат выходных данных

Два целых числа $a$ и $b$ через пробел, $|a|, |b| \le 2 \cdot 10^9$, $a + b = n$. Подойдёт любая подходящая пара.

## Пример

Вход: `5`. Допустимые выходы: `5 0`, `2 3`, `-10 15` и так далее.
