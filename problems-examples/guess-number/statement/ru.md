# Угадай число

Жюри загадало целое число $x$ от $1$ до $n$. Ваша задача отгадать его, задавая вопросы.

## Взаимодействие

Сначала программа жюри выводит число $n$ ($1 \le n \le 10^9$).

Затем ваша программа выводит по одному числу $q$ ($1 \le q \le n$) в отдельной строке. На каждое число жюри отвечает одним словом:

- `LESS`, если $x < q$;
- `GREATER`, если $x > q$;
- `EQUAL`, если $x = q$. После этого ответа программа должна завершиться.

Можно задать не более **32** вопросов.

**Не забывайте сбрасывать буфер вывода после каждого вопроса** (`flush`), иначе решение зависнет.
